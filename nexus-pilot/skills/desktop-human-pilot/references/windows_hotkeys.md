# Windows Operating System Keyboard Shortcut Reference

Use these keyboard combinations with `send_keystrokes(keys=[...])` for fast, deterministic control.

## System & Window Navigation
| Shortcut | Action |
|---|---|
| `["win", "r"]` | Open Windows Run Dialog |
| `["alt", "tab"]` | Switch to next application |
| `["alt", "f4"]` | Close active window |
| `["win", "d"]` | Show desktop / Minimize all |
| `["win", "e"]` | Open Windows File Explorer |
| `["win", "up"]` | Maximize current window |
| `["win", "down"]` | Restore / Minimize current window |
| `["ctrl", "shift", "esc"]` | Open Windows Task Manager |

## Application Editing & Document Control
| Shortcut | Action |
|---|---|
| `["ctrl", "s"]` | Save current document / project |
| `["ctrl", "z"]` | Undo previous action |
| `["ctrl", "y"]` | Redo action |
| `["ctrl", "a"]` | Select all text / elements |
| `["ctrl", "c"]` | Copy selection to clipboard |
| `["ctrl", "v"]` | Paste from clipboard |
| `["ctrl", "x"]` | Cut selection |
| `["ctrl", "f"]` | Find in page / file |
| `["ctrl", "w"]` | Close active tab |
| `["ctrl", "n"]` | New document / window |

## Developer IDEs (VS Code / Visual Studio)
| Shortcut | Action |
|---|---|
| `["ctrl", "shift", "p"]` | Open Command Palette |
| `["ctrl", "p"]` | Quick Open file search |
| `["ctrl", "`"]` | Toggle terminal |
| `["ctrl", "b"]` | Toggle primary sidebar |
| `["f5"]` | Start Debugging |
| `["shift", "f5"]` | Stop Debugging |
