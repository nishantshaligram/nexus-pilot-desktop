# Supported Windows Shortcuts Reference

Reference of standard keyboard shortcut combinations supported by `send_keystrokes(keys=[...])`.

---

## Operating System Navigation

| Keys Array | Action |
|---|---|
| `["win", "r"]` | Open Run Dialog |
| `["alt", "tab"]` | Switch Active Window |
| `["alt", "f4"]` | Close Active Application |
| `["win", "d"]` | Show Desktop / Minimize All |
| `["win", "e"]` | Open Windows File Explorer |
| `["ctrl", "shift", "esc"]` | Open Windows Task Manager |
| `["win", "up"]` | Maximize Active Window |
| `["win", "down"]` | Restore / Minimize Active Window |

---

## Browser & Document Navigation

| Keys Array | Action |
|---|---|
| `["ctrl", "l"]` | Highlight Address / Search Bar |
| `["ctrl", "t"]` | Open New Tab |
| `["ctrl", "w"]` | Close Active Tab |
| `["ctrl", "shift", "n"]` | Open Private / Incognito Window |
| `["ctrl", "f"]` | Find on Page / in File |
| `["ctrl", "s"]` | Save Current Document |
| `["ctrl", "a"]` | Select All |
| `["ctrl", "c"]` | Copy to Clipboard |
| `["ctrl", "v"]` | Paste from Clipboard |
| `["ctrl", "z"]` | Undo |
| `["ctrl", "y"]` | Redo |
